This project is a collection of console-based programs developed in C language based on Windows API, including some classic games. The project utilizes the console for rendering and provides fundamental functionalities through a core module (core), including console settings, audio playback, and scene rendering.

### Main Features

- **Console Settings**: Supports virtual terminal processing.
- **Audio Playback**: Provides the ability to play 8-bit sounds.
- **Scene Rendering**: Supports frame rate control, color blending, and scene drawing.

### How to Use

1. Clone the repository to your local machine.
2. Build the project using CMake.
3. Run the executable file for the desired game.
