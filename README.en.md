This project is a collection of console-based games developed in C language, including multiple classic games such as Snake, Tanks, and Tetris. The project utilizes the console for rendering and provides fundamental functionalities through a core module (core), including console settings, audio playback, scene rendering, and general utility functions.

### Main Features
- **Console Settings**: Supports virtual terminal processing, console font and size configuration, text selection disabling, and window position adjustment.
- **Audio Playback**: Provides the ability to play 8-bit sounds.
- **Scene Rendering**: Supports frame rate control, color blending, scene drawing, and object management.
- **General Utilities**: Includes practical functions such as configuration file loading, string processing, and matrix rotation.

### Game Modules
- **Snake (snakes)**: Implements classic Snake game logic, including snake movement, food generation, and collision detection.
- **Tanks (tanks)**: Provides tank control, shooting, collision detection, and auto-navigation functionality.
- **Tetris (tetris)**: Implements block generation, rotation, falling, and row elimination logic.

### How to Use
1. Clone the repository to your local machine.
2. Build the project using CMake.
3. Run the executable file for the desired game.
