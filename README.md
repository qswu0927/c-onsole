该项目是一个基于C语言开发的控制台游戏集合，包含了多个经典游戏，例如贪吃蛇（snakes）、坦克大战（tanks）和俄罗斯方块（tetris）。该项目利用控制台进行渲染，并通过核心模块（core）提供基础功能，包括控制台设置、音频播放、场景渲染和通用工具函数。

### 主要功能
- **控制台设置**：支持虚拟终端处理、控制台字体和大小设置、禁用文本选择和调整窗口位置。
- **音频播放**：提供播放8位声音的功能。
- **场景渲染**：支持帧率控制、颜色混合、场景绘制和对象管理。
- **通用工具**：包括配置文件加载、字符串处理、矩阵旋转等实用函数。

### 游戏模块
- **贪吃蛇（snakes）**：实现了经典的贪吃蛇游戏逻辑，包括蛇的移动、食物生成和碰撞检测。
- **坦克大战（tanks）**：提供坦克控制、射击、碰撞检测和自动导航功能。
- **俄罗斯方块（tetris）**：实现方块生成、旋转、下落和消除行的逻辑。

### 使用方法
1. 克隆仓库到本地。
2. 使用CMake构建项目。
3. 运行对应游戏的可执行文件。
